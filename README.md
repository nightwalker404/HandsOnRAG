# HandsOnRAG 🚀

> A hands-on learning journey from simple AI chat to a fully functional RAG system with vector databases and folder-based document ingestion.
 
**Status:** 🌱 In Development | Learning Project
 
---
 
## 🎯 Project Vision
 
HandsOnRAG is an iterative learning project designed to build a **Retrieval Augmented Generation (RAG)** system from the ground up. We start with basic AI chat responses and progressively add complexity—integrating vector databases, document embeddings, semantic search, and multi-document retrieval.
 
This is **not** a production system, but a hands-on exploration of RAG concepts using **Ollama** for local LLM inference.
